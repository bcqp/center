Validation protocol and audit trail

Validation is a documented comparison between a value used in BIQEP analysis and the corresponding value in the cited publisher's release. The status applies to the stated observation and retrieval record only.

01

Identify the statistical object

Confirm the indicator name, unit, population or coverage, frequency, reference period and price or index base. Similar labels may describe different statistical concepts.

02

Locate the primary release

Use the original statistical agency or central-bank release where available. Record the publication title, table or series identifier, release date and retrieval date.

03

Reproduce the observation

Read the exact period and unit, apply only documented conversions, and compare the resulting figure with the value stored in the register. Retain precision before display rounding.

04

Check revisions and breaks

Review footnotes, base-year changes, rebasing, seasonal adjustment, revised historical observations and methodological notes. Record any discontinuity that affects interpretation.

05

Record the result

Retain the source URL, retrieval date, observation period, value, unit, check outcome and explanatory note. If the match cannot be established, mark the observation as pending rather than verified.

International quality references

BIQEP's documentation approach is informed by the World Bank's overview of data quality frameworks, including the IMF/World Bank Data Quality Assessment Framework, and by the UN SDG indicator metadata repository. These frameworks emphasise documented concepts, sources, methods and quality dimensions. BIQEP's page-level checks are its own procedures and should not be represented as a formal DQAF assessment.

How a check is done

  • Find the original release on the publisher’s site.
  • Read the value for the stated period and note the retrieval date.
  • Compare it with the figure used. They must match exactly.
  • Record the result. If they do not match, the figure is not used until the difference is explained.
