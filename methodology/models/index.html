The open-source engine behind the estimates, and the families of model it offers.

Open Econometric Systems

Open Econometric Systems (OES) is a free, open-source econometric workspace. It currently offers 69 models and runs in the browser, so data stay on the user’s own computer. Its estimators are written in Python and can also be run from a laptop.

Open OES in your browser   Read the code on GitHub

Model families

Time series
OLS with diagnostics, ARDL bounds tests, nonlinear ARDL, VAR, VECM, instrumental variables and GMM, local projections, structural VARs, structural-break tests, threshold and smooth-transition regression, ARIMA, GARCH, quantile regression, cointegration tests and wavelet coherence.
Panel data
Pooled, fixed- and random-effects models, dynamic panel GMM, mean-group and common-correlated-effects estimators, panel local projections, panel threshold models and spatial panels.
Causal inference
Difference-in-differences, event studies, interrupted time series, regression discontinuity, synthetic control, matching and shift-share instruments.
Machine learning
LASSO, ridge, elastic net, random forest, XGBoost and double machine learning.
Bayesian
Bayesian regression and VARs with Minnesota and other priors, factor-augmented, time-varying and stochastic-volatility VARs, sign-restricted VARs and Bayesian local projections.
Markov switching
Markov-switching regression, autoregressions and VARs, including time-varying transition probabilities.

Model groups as listed in the OES repository. DSGE models are not part of OES and are solved elsewhere.
