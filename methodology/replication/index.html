Methodology

Replication

What is published with a brief so that a reader can repeat it.

A replication package contains

  • the dataset, with source and retrieval date for each series;
  • the model specification: variables, lags, sample, transformations and any break treatment;
  • the engine and its version;
  • the settings and random seeds for any simulation-based method;
  • the tables and charts as produced.

How to repeat a result

01

Open the engine

Use OES in a browser, or install it from the GitHub repository.

02

Load the data

Load the dataset from the package.

03

Apply the specification

Choose the model and enter the listed settings.

04

Compare

The output should match the tables in the brief.
