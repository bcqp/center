A practical environment for applied econometrics

Open Econometric Systems (OES) is an open-source econometric computing platform that allows users to select an econometric model, load a guide dataset or their own CSV file, prepare variables, specify an estimation and examine the resulting output in a web browser. The platform connects model implementation with methodological guides and Python code that researchers can reproduce outside the browser.

OES is designed as a research tool rather than a collection of static calculators. Its workflow brings together data preparation, model specification, estimation, result inspection and code reproduction. The available model catalogue and implementation details are maintained on the OES platform and its source repository.

From data to reproducible estimates

1. Select a model

Choose an estimator from the platform's model catalogue. The model guides explain the research use, specification and interpretation associated with the available methods.

2. Load data

Use the dataset supplied with a model guide or upload a CSV file. Panel workflows can use unit and time identifiers where required.

3. Prepare variables

Create lags, first differences, logarithms and growth rates; demean variables or restrict the estimation sample using the available data operations.

4. Specify and estimate

Set the model-specific options and run the estimator. The platform presents estimation output, tables and visual summaries where implemented.

5. Inspect and export

Review reported estimates and diagnostics, then export result tables or structured results where those options are provided by the selected model.

6. Reproduce in Python

Use the generated Python call and the published OES engine to reproduce the computation in a local research environment.

Computational design

Execution environment
Python runs in the browser through Pyodide, using scientific-computing packages including NumPy, pandas, SciPy, statsmodels, scikit-learn and XGBoost as required by the implementations.
Data handling
The OES page states that uploaded files are read on the user's device and are not uploaded to a server for estimation. Users should consult the live platform's current technical notes for details and limitations.
Model-specific implementations
Estimator implementations and supporting helper files are published with the OES guides and engine repository. The exact methods and options depend on the selected model.
Scope
OES covers the econometric workflows implemented in its current catalogue. DSGE models are handled separately through Dynare and are not part of the OES browser engine.

Testing and reproducibility

The OES platform includes an in-browser test suite that runs model examples and compares reported estimates with reference values. Its documentation describes checks against established Python packages and selected published results.

For empirical work, researchers should report the dataset source, sample, transformations, model specification, options and software version. The OES guides and generated Python calls are intended to make the computational steps easier to inspect and reproduce.

How OES relates to BCQP

The Bangladesh Center for Quantitative Policy (BCQP) focuses on quantitative economic research and evidence-based public-policy analysis. OES is presented here as computational research infrastructure associated with that broader mission: it provides a practical environment for implementing econometric methods, examining empirical relationships and supporting transparent analytical workflows.

BCQP's policy research and OES have complementary but distinct roles. BCQP develops and communicates research findings; OES provides computational tools that researchers can use in empirical analysis. OES does not itself determine BCQP's research conclusions, and the presence of a method in the platform does not imply that every BCQP publication uses that method.
